**[ НАЗВАНИЕ ПРОЕКТА ]**

RugShield - приложение для оценки трендов и рисков криптовалютных токенов.

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Цены на криптовалюты могут резко меняться за короткое время, в том числе из-за рыночных манипуляций. Анализ графиков цен и объёмов торгов даёт представление о движении рынка, но сам по себе не показывает, как участники переводят средства и какие кошельки могут быть связаны между собой. Из-за этого инвесторам сложно вовремя заметить формирование нового тренда, распознать возможный разворот и оценить риск потерь.

Цель RugShield - разработать систему, которая объединяет рыночные данные и данные блокчейна, чтобы выявлять признаки изменения тренда и помогать пользователям оценивать риски инвестиционных решений.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Потенциальная аудитория - частные инвесторы и другие пользователи, которые анализируют криптовалютные токены и хотят учитывать движение средств в блокчейне наряду с ценой и объёмом торгов.

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]**

Планируемый формат - веб-приложение. Для работы с ним пользователю понадобятся браузер и доступ в интернет. Для получения рыночных и блокчейн-данных приложению потребуется доступ к внешним API.

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

1. Выбирать криптовалютный токен для анализа.
2. Получать и проверять данные о цене, объёме торгов и транзакциях в блокчейне.
3. Определять текущий тренд за анализируемый период - восходящий, нисходящий или без выраженного направления.
4. Показывать признаки возможного изменения тренда, если они обнаружены.
5. Оценивать рыночный риск по токену с учётом рыночных показателей и движения средств между кошельками.
6. Объяснять, какие данные и признаки повлияли на обе оценки, и сообщать, если данных для оценки недостаточно.

Результат проекта - рабочий прототип, исходный код на GitHub, инструкция по запуску и примеры анализа токенов для демонстрации.

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

- DEX Screener показывает графики цен и объёмы торгов по торговым парам. [Документация DEX Screener](https://docs.dexscreener.com/tradingview-charts)
- Bubblemaps визуализирует распределение токенов между крупными держателями и переводы между их кошельками. [Документация Bubblemaps](https://wiki.bubblemaps.io/bubblemaps-v2/how-does-it-work)
- GoPlus Token Security API предоставляет данные о безопасности токенов. [Документация GoPlus](https://docs.gopluslabs.io/reference/tokensecurityusingget_1)
- RugCheck проверяет токены в сети Solana и показывает факторы риска, включая концентрацию токенов у крупных держателей и состояние ликвидности. [RugCheck](https://rugcheck.xyz/)

В RugShield я планирую сопоставлять изменения цены и объёма торгов с активностью кошельков за тот же период. В интерфейсе будут представлены две оценки с пояснениями - текущий тренд и уровень риска.

**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

- Среда разработки, Git и GitHub для работы с кодом и отслеживания изменений.
- Внешние API рыночных и блокчейн-данных, их документация и исторические данные для проверки алгоритмов.
- Язык программирования и фреймворк - Python и FastAPI для серверной части. Для обработки данных и обучения моделей используются NumPy и scikit-learn.
- Хранение данных - SQLite по умолчанию при локальном запуске, PostgreSQL при запуске через Docker Compose.
